# flock 0.8.1

The new goose in the Dock, and file paths you can click.

- The app icon is the redrawn goose: in flight, wing raised, on the same
  dark plate as before. 0.8.0 shipped the new bird inside the app but still
  the old one on the icon.
- Paths an agent prints relative to where it runs (`src/settings/theme.ts`,
  `Read(src/checkout/Steps.tsx)`, `tests/checkout.test.ts:12`) are links now,
  as absolute paths already were. A path only underlines once flock finds the
  file under the agent's folder, so prose with dots and slashes in it stays
  plain. This works in popped-out agent windows too.
- `file://` links open, whether an agent prints one or sends it as a
  terminal hyperlink (OSC 8); those used to be refused.
- Clicking a file follows the same rule as before: documents, images and
  source open in their usual app, and anything that could run (an app, a
  script, a binary) is shown in Finder instead.

## Security

- The bundled SQLite moves to 3.54 (libsqlite3-sys 0.39), fixing
  CVE-2026-119375 / RUSTSEC-2026-0459: a crafted database and write-ahead-log
  pair could make queries return uninitialized memory. flock only opens its
  own database in `~/.flock`. Until sqlx releases the change it has already
  merged, flock carries sqlx-sqlite with that one version bound relaxed
  (`vendor/sqlx-sqlite/FLOCK_PATCH.md`).

## Known limitations

- A path opens in the file's default app; the line number after a colon is
  not passed to an editor yet.
- Presence and sessions still need the server rollout described in the
  0.8.0 notes (migration `013_social_privacy.sql` and the new presence-auth
  service). Until then friends show offline.
- Docker workspace isolation has a known Git-configuration escape: repository-controlled Git configuration can execute commands on the host. Do not rely on this boundary for untrusted repositories or agent code.
