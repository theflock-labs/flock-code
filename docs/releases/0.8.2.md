# flock 0.8.2

A frozen window now recovers by itself, and a reload no longer starts your
agents twice.

- flock's window runs in its own web view process, separate from your agents.
  With several busy Claude Code panes that process could grow to many
  gigabytes, until the Mac swapped so hard that nothing in the window could be
  clicked while the agents kept working. flock now watches it: when it passes
  a quarter of your Mac's memory (kept between 3 and 8 GB), or when the visible
  window has not answered for three minutes, flock restarts just the web view.
  It does this at most once every ten minutes and tells you when it has. Your
  agents keep running throughout.
- After the window reloads, for any reason, flock reconnects to the agents
  that are still running instead of starting each one a second time. Before,
  a reload left the originals running out of sight next to fresh copies.
- Token costs are now counted for Claude models used through Bedrock or Vertex
  (names like `eu.claude-5.5-opus` or `eu.claude-5.1-fable`), for Opus, Sonnet
  and Haiku 5.5 and Fable 5.x, and Claude Code's `<synthetic>` messages count
  as free instead of unpriced.
- The terminals' glyph cache has a ceiling, and the graph's Docker checks give
  up after 10 seconds instead of waiting on an unresponsive Docker.
- `~/.flock/desktop.log` now records the window's memory, main-thread stalls
  and a window that has stopped answering (lines with `watchdog`), so a freeze
  leaves a trace to look at.

## Known limitations

- What makes the web view grow is not pinned down yet. 0.8.2 bounds it and
  recovers from it rather than removing the cause.
- Presence and sessions still need the server rollout described in the
  0.8.0 notes (migration `013_social_privacy.sql` and the new presence-auth
  service). Until then friends show offline.
- Docker workspace isolation has a known Git-configuration escape: repository-controlled Git configuration can execute commands on the host. Do not rely on this boundary for untrusted repositories or agent code.
