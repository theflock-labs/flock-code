# flock 0.8.3

Hand an agent a screenshot, see what each one is doing, and know when it is
done.

- The new-agent box takes screenshots and files: paste them, drop them on it,
  or use the paperclip. Images are saved into the folder the agent starts in
  (its worktree too) and named at the end of its first prompt, so "here's the
  bug, fix it" works in one step. Dictation now types into the box as well.
- Each thread shows what its agent is doing right now: "Editing
  src/checkout/Steps.tsx", "Run the tests", "Opening localhost:3000 in Wink",
  with its to-do progress (2/5) beside it. The page an agent opened in Wink
  stays in the thread's header for the rest of its turn.
- An agent that finishes while you are looking elsewhere is marked "done"
  until you open it, and a "Ready for review" row counts them. ⌘J goes
  through the agents waiting on you first, then the finished ones.
- A turn that stops short says why: "Lyra stopped: hit its rate limit", in
  the sidebar and as a note.
- ⌘Z undoes again in the new-agent box, Settings and search. Shortcuts that
  mean nothing to a text field (⌘N, ⌘J, ⌘1–9) still work there.

## How it knows

Claude Code reports each tool call, a failed turn and its tasks to small
hooks flock installs next to the ones it already had (Settings →
Integrations). They run only inside a flock agent, add a few milliseconds per
tool call, and print nothing Claude Code reads, so they can never approve or
block anything. They need the hooks to be installed, and a recent Claude
Code.

## Known limitations

- What makes the window's web view grow is not pinned down yet. 0.8.2 bounds
  it and recovers from it rather than removing the cause.
- Presence and sessions still need the server rollout described in the
  0.8.0 notes (migration `013_social_privacy.sql` and the new presence-auth
  service). Until then friends show offline.
- Docker workspace isolation has a known Git-configuration escape: repository-controlled Git configuration can execute commands on the host. Do not rely on this boundary for untrusted repositories or agent code.
